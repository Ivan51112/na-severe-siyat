Настоящий документ подготовлен по результатам анализа исходного кода из папки `Сайт охота за северным сиянием` на соответствие Техническому заданию Aurora Polaris v1.0.

## 2. Оставшиеся ограничения и открытые вопросы

1. **Реальный адрес Telegram-канала:**
   В коде используется переменная окружения `NEXT_PUBLIC_TELEGRAM_URL` (по умолчанию `https://t.me/aurora_polaris_signals`). Заказчику необходимо передать точный username / ссылку на канал.
2. **Лицензирование Open-Meteo:**
   Бесплатный тариф Open-Meteo разрешает только некоммерческое использование. Для коммерческого проекта (при монетизации рекламой) требуется коммерческая подписка или переход на Yr.no / MET Norway.
3. **Реальная верификация порогов светофора:**
   Текущие пороги (NOAA OVATION >= 20, облачность <= 25% для зелёного) являются математической моделью. В процессе полевого тестирования их необходимо калибровать по фактическим отчётам очевидцев в чате.
