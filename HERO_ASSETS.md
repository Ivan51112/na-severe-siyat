# Фоны первого экрана

Для каждого места подготовлены широкие кадры 1672 × 941 px. Файлы находятся в public/images:

| Место | День | Плотные облака | Дождь | Ночь с сиянием |
| --- | --- | --- | --- | --- |
| Мурманск | hero-murmansk-day.png | hero-murmansk-cloudy.png | hero-murmansk-rain.png | hero-murmansk-aurora.png |
| Териберка | hero-teriberka-day.png | hero-teriberka-cloudy.png | hero-teriberka-rain.png | hero-teriberka-aurora.png |
| Кировск | hero-kirovsk-day.png | hero-kirovsk-cloudy.png | hero-kirovsk-rain.png | hero-kirovsk-aurora.png |

Режим создания: встроенный imagegen, редактирование локальных референс-кадров. Общий набор запросов: фотореалистичная горизонтальная панорама 16:9 для адаптивного первого экрана; узнаваемый ориентир в правой половине, место под белый текст слева; естественный северный свет и сдержанный цвет; без надписей, логотипов и элементов интерфейса. Для Мурманска ориентир — ледокол «Ленин», для Териберки — расписной корабль на берегу, для Кировска — круглое здание «Плато» и Хибины. Варианты неба: ясная тёмная ночь с правдоподобным сиянием; пасмурный день; полностью закрытое небо; естественный дождь без графических полос. Для Кировска зимний дневной кадр не содержит прямого солнца.

Это иллюстрации, не снимки текущего неба. Поскольку при генерации использовались исходные фотографии из папки проекта, перед публичной публикацией нужно подтвердить право использовать эти референсы.
