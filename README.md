# Аврора Мурманск

Лендинг для туристов: текущая облачность в Мурманске, Териберке и Кировске и один основной переход в Telegram-канал. Цель первой версии — проверить, переходят ли посетители сайта в канал.

Главная страница показывает облачность по погодной модели, время погодных данных и фон-иллюстрацию места. Иллюстрация не является веб-камерой. Если свежих данных нет, сайт не показывает выдуманную оценку. Страница `/preview` позволяет увидеть мобильный и компьютерный вид и демонстрационные состояния неба. Старые ссылки на `/forecast` перенаправляются на главную: демонстрационный график больше не входит в путь посетителя.

## Telegram

Канал пока не создан. Поэтому основная кнопка честно показывает, что переход ещё не подключён. Когда появится ссылка, задайте `NEXT_PUBLIC_TELEGRAM_URL=https://t.me/имя_канала` и пересоберите сайт. После этого кнопка станет ссылкой; нажатие отправит событие `telegram_click`.

Бот для сводок и публикация фотографий появятся позже. Сейчас сайт не обещает уже работающих оповещений. Текущая аналитика хранится только в памяти процесса, поэтому для количественной проверки гипотезы после деплоя понадобится постоянное хранилище или отдельная аналитика.

## Запуск

`npm install`, затем `npm test`, `npm run build`, `npm run start -- -p 3002`.

Сайт: http://127.0.0.1:3002/ · просмотр двух экранов: http://127.0.0.1:3002/preview
